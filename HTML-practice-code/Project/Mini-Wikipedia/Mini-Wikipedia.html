১. ওয়েব ডেভেলপমেন্টের তিনটি মূল স্তম্ভ

HTML (HyperText Markup Language)

ওয়েবসাইটের মূল কঙ্কাল বা ভিত্তি তৈরি করে। এটি নির্ধারণ করে পৃষ্ঠায় কোথায় টেক্সট, বাটন বা ছবি থাকবে।

"HTML হলো ওয়েবের ভিত্তি—কন্টেন্টকে অর্থবহ ও অ্যাক্সেসিবল করতে সেমান্টিক ট্যাগ অপরিহার্য।"

CSS ও JavaScript

CSS: রঙের ছোঁয়া ও লেআউট নির্ধারণ করে।
JavaScript: লজিক ও ইন্টারঅ্যাক্টিভিটি যোগ করে।

প্রোগ্রামিং স্যাম্পল কোড দেখতে চাইলে:

<h1>হ্যালো বাংলাদেশ!</h1>

২. প্রযুক্তিগত তুলনা তালিকা

ওয়েব ট্রিনিটি (Web Trinity) তুলনা
প্রযুক্তি ভূমিকা শেখার ধাপ ফাইল এক্সটেনশন
HTML কন্টেন্ট ও স্ট্রাকচার ১ম ধাপ (সহজ) .html
CSS ডিজাইন ও রেসপনসিভনেস ২য় ধাপ (মাঝারি) .css
JavaScript ফাংশনালিটি ও ডাটা হ্যান্ডলিং ৩য় ধাপ (উন্নত) .js

৪. সচরাচর জিজ্ঞাসিত প্রশ্নাবলী (FAQ)

(প্রশ্নগুলোর ওপর ক্লিক করলে উত্তর বের হবে)

শুধু HTML দিয়ে কি ফুল ওয়েবসাইট তৈরি করা সম্ভব?

হ্যাঁ, তথ্যবহুল ও ডকুমেন্টেশন সাইট শুধু HTML দিয়েই বানানো যায়। তবে আকর্ষণীয় ডিজাইন ও রেসপনসিভ লুকের জন্য পরবর্তীতে CSS দরকার হয়।

সেমান্টিক ট্যাগ (Semantic Tags) কী এবং কেন দরকার?

<header>, <nav>, <article> ইত্যাদি হলো সেমান্টিক ট্যাগ। এগুলো সার্চ ইঞ্জিন (SEO) এবং স্ক্রিন রিডারের জন্য পেজের অর্থ পরিষ্কার করে তোলে।

কোড রান করতে কী সফটওয়্যার লাগবে?

যেকোনো কোড এডিটর (যেমন: VS Code) এবং যেকোনো ব্রাউজার (যেমন: Chrome, Edge)।
