# 🌐 TechPedia – ওয়েব ডেভেলপমেন্ট নলেজ পোর্টাল

TechPedia হলো একটি পূর্ণাঙ্গ টেকনিক্যাল নলেজ হাব (Knowledge Base / Mini Wikipedia), যা সম্পূর্ণ পিওর **HTML5** দিয়ে তৈরি করা হয়েছে। কোনো এক্সটার্নাল CSS বা JavaScript ফ্রেমওয়ার্ক ছাড়া কীভাবে শুধুমাত্র সেমান্টিক এবং আধুনিক HTML ট্যাগ ব্যবহার করে একটি ইন্টারঅ্যাক্টিভ ও গঠনমূলক ওয়েবসাইট তৈরি করা যায়, তা এই প্রজেক্টে ফুটিয়ে তোলা হয়েছে।

---

## 📌 প্রজেক্টের বৈশিষ্ট্যসমূহ (Key Features)

- **সেমান্টিক গঠন (Semantic Architecture):** SEO এবং অ্যাক্সেসিবিলিটি নিশ্চিত করতে `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, এবং `<footer>` ট্যাগের সঠিক ব্যবহার।
- **স্মার্ট সূচিপত্র (In-page Navigation):** পেজের শুরুতে একটি টেবিল অব কন্টেন্টস রয়েছে, যার মাধ্যমে পেজ রিলোড ছাড়াই যেকোনো সেকশনে জাম্প করা যায়।
- **বিশ্লেষণমূলক টেবিল (Comparison Table):** HTML, CSS এবং JavaScript-এর তুলনামূলক ছক (`<table>`, `<caption>`, `<thead>`, `<tbody>`)।
- **ইন-বিল্ট মাল্টিমিডিয়া (Native Media Support):** ব্রাউজারের নিজস্ব অডিও (`<audio>`) ও ভিডিও (`<video>`) প্লেয়ার।
- **ডেটা ভিজ্যুয়ালাইজেশন গেজ (Progress & Meter):** শেখার অগ্রগতি এবং স্টোরেজ ব্যবহারের জন্য `<progress>` ও `<meter>` ট্যাগের ব্যবহার।
- **জিরো-জেএস অ্যাকর্ডিয়ন (Pure HTML FAQ Accordion):** জাভাস্ক্রিপ্ট ছাড়াই ক্লিক করে প্রশ্ন-উত্তর দেখার সুবিধা (`<details>` ও `<summary>`)।
- **অ্যাডভান্সড ইনপুট ফর্ম (Interactive Form):** টেক্সট, ইমেইল, ডেট পিকার, রেডিও বাটন, চেকবক্স এবং সার্চ সাজেশনের জন্য স্মার্ট ড্রপডাউন (`<datalist>`) সম্বলিত কন্ট্রিবিউশন ফর্ম।

## 🛠️ ব্যবহৃত প্রযুক্তি (Tech Stack)

- **ভাষা:** HTML5 (Pure Vanilla HTML)
- **স্টাইলিং:** ব্রাউজারের ডিফল্ট ইউজার এজেন্ট স্টাইলশীট (No CSS used)
- **স্ক্রিপ্টিং:** কোনো জাভাস্ক্রিপ্ট ব্যবহার করা হয়নি (No JS used)
