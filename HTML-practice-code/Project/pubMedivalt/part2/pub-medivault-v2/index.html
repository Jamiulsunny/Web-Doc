PUB MediVault is a student project built by a PUB student team. It is not an official university service.

Paper records get lost. Shared records get misused.

Medical history is scattered across clinics, labs and folders at home. PUB MediVault keeps it in one vault the patient owns. Doctors request access, the patient approves specific records for a set time, and every access is written to an audit trail. A stored hash lets anyone check that a report was not altered.

How it works

  1. Create your accountRegister as a patient, doctor or institution.
  2. Upload medical recordsEach file is encrypted and hashed.
  3. Grant doctor accessPick records and a duration.
  4. Verify record integrityCompare today's hash with the registered one.
  5. Track every accessSee who opened what, and when.

Security and privacy

Encryption

AES-256-GCM with a unique nonce per file. Keys stay on the server, never in the browser.

Access control

Every request is checked on the server against your current consent. Revoking blocks all future access.

Revocation limits

Revoking stops new access. It cannot erase a copy someone already downloaded.

Audit events

The chain stores hashes, pseudonymous IDs and timestamps. No names, no diagnoses.

This project is a demonstration with synthetic data. It is not security-audited or certified, and it is not an official Pundra University service.

Questions

Can administrators read my medical files?

No. Admins manage accounts, verification and security events, not document content.

Is my health data on the blockchain?

No. Only a hash, a pseudonymous record ID, event type and timestamp are recorded.

Does Zenva AI diagnose diseases?

No. It explains terms and platform features, and tells you to see a qualified professional.

Are the testimonials real?

There are none on this page. Any shown in demo mode will be labelled as samples.
