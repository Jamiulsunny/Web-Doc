# PUB MediVault (frontend demo)

Open `index.html` in a browser. Keep the `assets/` folder next to it.

- Landing page styled after the Pundra University site (student project, not an official university service)
- Live demo: AES-256-GCM encryption, SHA-256 hash, consent grant/revoke, audit trail (blockchain is a local mock)
- Zenva AI: rule-based demo answers in Bangla and English
- Not included yet: Node/Express backend, PostgreSQL/Prisma, real login, Sepolia contract, Gemini API

Edit the Chairman card text in `index.html` (id `messages`) and check the portrait is correct.
