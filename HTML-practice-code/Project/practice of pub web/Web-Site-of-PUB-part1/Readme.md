# 🎓 Pundra University Website Recreation

A modern, responsive, and feature-rich recreation of the **Pundra University of Science & Technology (PUB)** website, built using HTML5, CSS3, and Vanilla JavaScript.

## 📌 Project Overview

The **Pundra University Website Recreation** project aims to recreate the university's website structure and user experience with a clean layout, responsive design, interactive components, and organized navigation.

This project is developed for educational purposes to practice frontend web development and recreate a university website using core web technologies.

## ✨ Key Features

- 🏠 **Homepage:** Image slider, notice board, academic programs, university messages, and events.
- 🏛️ **About University:** University overview, vision, mission, Board of Trustees, and Syndicate.
- 👨‍💼 **Administration:** Chancellor, Vice-Chancellor, Registrar, and Proctorial Body.
- 📝 **Admission:** Admission requirements, fee structure, and online admission form.
- 📚 **Academics:** Faculties of Science, Business, Humanities & Law, with program listings.
- 📢 **Notice Archive:** Searchable and filterable notices with pagination.
- 📅 **Events:** Seminars, conferences, cultural programs, and sports events.
- 📍 **Contact:** Campus location, Gokul, Bogura address, directory, and query form.
- 📱 **Responsive Design:** Layout optimized for desktop, tablet, and mobile screens.
- ⚡ **Interactive UI:** Navigation drawer, dropdown menus, carousel slider, filters, and dynamic tabs.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and semantic content |
| CSS3 | Styling, layouts, animations, and responsiveness |
| JavaScript | Interactive components and dynamic functionality |

**No frontend framework is required.** The project uses Vanilla JavaScript alongside standard HTML and CSS.

## 🚀 Getting Started

### 1. Download or Clone the Project

Download the project files or clone the repository to your computer.

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your actual Git repository URL.

### 2. Open the Project

Open the `pundra-university-recreation` folder in Visual Studio Code.

### 3. Run the Website

Open `index.html` in your browser, or use the **Live Server** extension in VS Code for a better development workflow.

### 4. Explore the Pages

Use the website navigation to visit the Home, About, Administration, Admission, Academics, Notice, Events, and Contact pages.
