# Pundra University recreation
Open the folder in VS Code → right-click index.html → Open with Live Server.
- Text: edit each page's <main>, or the lists in build.py then re-run `python3 build.py`.
- Colors/fonts: css/style.css (:root variables; approximated, not extracted from the original).
- Photos: images in assets/images are SVG placeholders. Replace by saving a real photo with the same name (e.g. campus.jpg) and update the src, or edit the K map in build.py.
- Navigation: NAV list in build.py.
