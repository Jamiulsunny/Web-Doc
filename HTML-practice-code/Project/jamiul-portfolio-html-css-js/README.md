# Jamiul Islam Sunny — HTML, CSS & JavaScript Portfolio

This version does not need React, Next.js, Tailwind, npm, or any build process.

## Run in VS Code
1. Extract the ZIP and open the folder in VS Code.
2. Open `index.html` in a browser or use the Live Server extension.
3. The website uses `style.css` for styling and `script.js` for interactions.

## Customize
- **Logo:** Edit the `JS.` text inside `.brand-logo` in `index.html`. You can replace it with an image element if you have a logo file.
- **Profile photo:** Replace the URL in `.portrait-img` with `assets/images/profile.jpg` after adding your own image there.
- **Email:** Change `jamiulsunny476@gmail.com` in `index.html` and `script.js` if needed.
- **Projects and bio:** Replace sample text and links with your actual work and verified details.
- **Theme:** Use the blue, amber, and violet circles in the navbar.

The contact form is front-end only. It prepares an email through the visitor's default mail app; it does not send email through a server. Google Fonts and the example profile image require internet access.
